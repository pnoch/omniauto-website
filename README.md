# OmniAuto website

Landing page for OmniAuto, served by GitHub Pages at
<https://omniauto.siamcreations.app/>.

The page is at the repository root (`index.html`, `styles.css`,
`screenshots/`, `CNAME`). The rolling Android test build lives in the
`pnoch/omniauto-releases` repository:

<https://github.com/pnoch/omniauto-releases/releases/tag/android-latest>

This is a debug-signed test build, not a production release.
